## About me

I'm an independent developer interested in designing and building software, rather than only using existing tools. My work and experiments focus on game technology, programming languages, developer applications, Linux software and artificial intelligence.

I enjoy taking an idea from its architecture and technical design through implementation, testing and refinement. I value modularity, performance, maintainability and clear documentation.

- **Main interests:** game engines, compilers, programming languages, desktop software and AI.
- **Development environment:** Linux.
- **Approach:** learn by building, experiment, test and improve.
- **Current profile:** ZCodeGX — a central place for my projects and technical work.
